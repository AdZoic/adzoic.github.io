# adzoic.github.io

The AdZoic blog, built by GitHub Pages with Jekyll. Live at https://adzoic.github.io.

To add a post, create `_posts/YYYY-MM-DD-slug.md` with front matter:

```yaml
---
title: "Post title"
description: "One or two sentences shown on the home page and in link previews."
image: /assets/img/cover.svg   # optional
tags: [Tag, Another]
---
```

Push to `main` and GitHub Pages publishes it within a minute or two.
